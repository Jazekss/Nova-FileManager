## Nova File Manager 1.2.0 + Nova Transfer 1.2.0

New look: the new Nova icon on both apps.

### Downloads
| File | For |
|---|---|
| `NovaFileManager_1.2.0_android-arm64-v8a_….apk` | Almost every modern Android phone |
| `NovaFileManager_1.2.0_android-armeabi-v7a_….apk` | Older 32-bit phones |
| `NovaTransfer_1.2.0_windows-setup_….exe` | Windows 10/11 companion (installs to `Program Files\JKapps\Nova Transfer`) |

### New on the phone
- **Installed apps.** Your own apps with version, size and when each was last used. Tap an app to uninstall it or open its info. Tick several to uninstall them one after another; Android confirms each one. Afterwards Nova finds the folders the apps left in your storage and offers to delete them.
- **Cleaner.** Shows how much cache each app holds and clears all app caches at once (Android 11+, confirmed by the system). It also finds unneeded files: thumbnail caches, cache and temp folders, logs, empty folders and leftovers of uninstalled apps. Safe items are ticked in advance; nothing is deleted without asking.
- **Files by category.** Images, videos, audio, documents, archives, APKs, large files and others, each with count and size. Sort, select, move or delete (to the recycle bin), always with a confirmation.
- **New Home layout:** Installed apps, Files, PC share, Other devices, Vault, Recycle bin.
- **PC share** now lists your other devices right below your own PC.
- Google Drive and Google sign-in have been removed.

### Connection
- Manual pairing accepts the address in any form (with `http://`, spaces or commas). If you type the "Other devices" code into "My PC", Nova tells you which code to use.
- Phones now hold a Wi-Fi multicast lock, so devices find each other on the LAN more reliably.

### Note
For full app sizes and last-used times, allow **Usage access** once; the Installed apps screen has a button for it.
