## Nova File Manager 1.1.0 + Nova Transfer 1.1.0

Install **both**: the phone and the PC must run 1.1.0, because the link protocol changed.

### Downloads
| File | For |
|---|---|
| `NovaFileManager_1.1.0_android-arm64-v8a_….apk` | Almost every modern Android phone |
| `NovaFileManager_1.1.0_android-armeabi-v7a_….apk` | Older 32-bit phones |
| `NovaTransfer_1.1.0_windows-setup_….exe` | Windows 10/11 companion. The installer also allows Nova Transfer through Windows Firewall |

### New
- **Other devices.** Link any number of extra phones and PCs, phone ↔ phone too. Pair by QR, or by address + one-time code. Every device has a name you can change. On the PC each device gets its own tab.
- **Per-folder sharing.** Share a PC folder with *only my phone*, *all devices* or the devices you pick. Phones can share folders with all devices or with specific ones.
- **Pairing without a camera.** The PC shows its address and a one-time code that you type on the phone.
- **Self-healing link.** Open Nova on both devices and they find each other again, including after restarts, Wi-Fi drops or a new IP address.
- **Thumbnails everywhere.** Videos (with a ▶ badge), HEIC photos, audio cover art and APK icons now have thumbnails. The PC uses the same thumbnails Explorer shows. Thumbnails are on by default.
- **File-type icons** for audio, video, documents, archives and more, on both devices.
- **HEIC preview.** Samsung HEIC photos open on the phone, and on the PC through automatic JPEG conversion.

### Fixed
- **Faster, steadier transfers.** Files now stream in encrypted 256 KB chunks. Phones encrypt with Android's hardware AES. Big videos no longer freeze the PC or drop the connection ("PC not reachable").
- **Steadier photo swiping.** Pinch-zooming no longer flips to the next photo: a page swipe has to travel about 5 mm with one finger.
- **Manual pairing.** Typing an address on the phone no longer says "invalid link".
- **Status.** The PC shows "connected" only while the phone is actually there.

### Security
- Pairing uses an X25519 key exchange authenticated with a single-use 60-bit code. Each pair of devices gets its own 256-bit key.
- Every request is signed (HMAC-SHA256 with timestamp and nonce), and all data is AES-256-GCM encrypted.
- A device sees only the folders shared with it. `..`, symlink and junction tricks are blocked, and other devices can't delete or rename files.

### Install location
Nova Transfer now installs to `Program Files\JKapps\Nova Transfer`, and its data lives in `%APPDATA%\JKapps\Nova Transfer`. The installer moves old installs there, and existing pairings and settings are kept.
